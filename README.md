# Worst Fix Ever: Funniest Commit Message

## The entry

> fix: login crash fixed by deleting the login page

**Character count: 49** (limit: 100)

## Why it lands

The joke is the fix itself: the crash is technically gone, because the page users crashed on no longer exists — the repair "worked" by destroying the thing it was supposed to save. It reads exactly like a real commit subject a tired engineer would type at 2 a.m., short, plain, and deadpan, with the absurdity doing all the comedy work. And it finds a fresh angle — no revert, no production test, no "broke everything" — just a cure worse than the disease, delivered in one flat sentence.
